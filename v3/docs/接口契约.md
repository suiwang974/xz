# SniffDL v3 内核接口契约（WP1，2026-11-09）

> 归属 WP1。代码真相在 `core/api.py`（注册表）与 `core/engine.py`；本文与之不符时以代码为准并回来改本文。
> 测试：`tests/core_unit.py`（真内核 + HTTP，60 项，11-09 全过）、`tests/ui_smoke.py`。

## 1. 传输与鉴权
- 地址：`POST http://127.0.0.1:<port>/jsonrpc`，JSON-RPC 2.0，`params` 一律是**位置数组**。端口见运行时握手文件（`--runtime`）或 `sniffdl.ping`。
- 令牌：除下表标「免令牌」的方法外，都要请求头 `X-SniffDL-Token: <token>` 或 `Authorization: Bearer <token>`（令牌由宿主 `--ui-token` 传给内核）。缺/错 → `error.code = -32001`「需要界面令牌」。
- Host 头只接受本机名（防 DNS 重绑定）。事件流：`GET /events`（SSE），界面静态页：`/ui/`。
- 错误码：`-32001` 缺令牌；`-32602` 参数不对（中文 message）；`-32601` 无此方法。业务失败多数不抛错，而是返回 `{ok:false, error:"中文原因"}`。
- `aria2.*` 与旧版 `sniffdl.*`（扩展 / LinkSwift 在用）不在本注册表，保持原样（端口 6800、无 token 可推送）。

免令牌（`ui=False`）：`sniffdl.ping`、`sniffdl.takeoverRules`、`sniffdl.grabber.push`。

## 2. 事件（SSE /events，`event:` 名 → data）
`snapshot`（连上即发：tasks/stats/queues/pending/grabber/version/port）、`tasks`、`stats`（含 `{reset:true}`）、`log`、`notify`（kind=started/done/error）、`settings`（`{changed:{…}}`，密钥类只发 `********`）、`limit`、`power`（state=countdown/done/cancelled）、`quit`、`intercept`、`clip`、`grabber`、`queues`、`port`、`say`、`hello`、**`slow`**（慢速取片任务结束时发一次，内容同 slowStatus）。

## 4. 设置键（WP1a 11-09 新增，全部在 `core/settings.py` SCHEMA）
| 键 | 类型/默认 | 说明 | 消费方 |
|---|---|---|---|
| speed_engine | select auto/aria2/sdl，auto | 直链引擎；任务视图 `engine` 字段 = 实际用的 sdl/aria2 | ✅ engine._http_aria2c（auto 失败回退 aria2；sdl 失败即任务失败） |
| sidecar_m3u8 | bool true | m3u8/mpd 交 N_m3u8DL-RE | WP1 接 core/sidecars.py（待） |
| sidecar_bili | bool false | B 站交 BBDown | 同上 |
| sidecar_paths | text | 每行 名称=路径 | core/sidecars.py |
| bt_upload_limit_kbps | int 0 | BT 上传限速 | ✅ engine：启动参数 `--max-overall-upload-limit` + 改设置热更新 |
| rt_enable / rt_base_url / rt_api_key(secret) / rt_model / rt_instructions | | 实时语音网关；密钥 settings.get 只回 `********`，回传掩码不覆盖 | rt.test/models ✅；桌宠页（WP4） |
| incomplete_dir | path "" | 未完成文件临时目录 | ✅ engine（直链 sdl/aria2 两条路；yt-dlp 视频、BT、旧单连接 .part 路径未接） |
