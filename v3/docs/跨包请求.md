```python
from . import speed as SPD          # 文件顶部

    def _http_aria2c(self, url, outdir, name, headers, prog=None, cancel=None, conn=None, min_split="1M",
                     status_cb=None):
        m = SPD.mode(self)                       # auto / aria2 / sdl（settings.speed_engine）
        if m != "aria2":
            try:
                return SPD.run_http(self, url, outdir, name, headers, prog, cancel, conn, min_split, status_cb,
                                    task=getattr(_TL, "task", None))
            except SPD.Fallback as e:
                if m == "sdl":
                    raise RuntimeError("动态分片失败：%s" % e)
                self.log("[直链] 动态分片不接（%s），回退 aria2c…" % str(e)[:90])
                if status_cb:
                    status_cb("动态分片失败，改用 aria2c…")
            # _AbortSignal（暂停/取消）与 RuntimeError（404/410/过期/磁盘满）原样上抛：
            # 原 _rpc_direct_file 对 404/410/过期直接 _fail，其他 RuntimeError 会再走单连接兜底
        _TL.in_aria2 = True
        ...（原有 aria2 代码不变）
```

要点：
1. **限速**：run_http 在 sdl_speed 每条连接线程里扣 `self.gbucket` 与 `self._buckets[gid]`（与 `_throttled_prog` 同一个桶），运行期间自己置 `_TL.in_aria2=True`，外层 `_throttled_prog` 不会重复扣；改限速（`_apply_limits` → `gbucket.set_rate`、`task_set_limit` 改 `limit_kbps`）下一个控制周期（≤0.25s）生效。实测见下。
2. **任务**：run_http 用 `task=` 或 `core.engine._TL.task` 找任务（读 `limit_kbps`、`conns`、`a2opts`、`cancel`，写 `conns_eff`、`speed_engine="sdl"`）。`_TL.task` 必须在 `_rpc_run_task` 里已设置（现在就是）。
3. **临时文件**：`<name>.sdl` + 侧车 `<name>.sdlpart`。同 URL 同文件名再次进来自动续传。**请把 `.sdlpart` 加进 engine.py 两处清理列表**（约 569 行覆盖 `(".aria2", ".part", ".sdl", ".sdl.aria2")`、约 1215 行取消清理 `(".part", ".aria2", ".sdl", ".sdl.aria2")`）。
4. **与 aria2 互不踩**：存在 `<name>.aria2` / `<name>.sdl.aria2` 时 run_http 直接 Fallback（让 aria2 续自己的）；抛 Fallback 前已删掉 `.sdl/.sdlpart`，aria2 不会撞上预分配的半成品文件。旧版 `.part` 续传（`resume>0`）不进这个分支，不受影响。
5. **连接数**：命中网盘规则 → 上限 `ND.profile_conn(prof, cfg, conn)`（≤16），min_split 用规则值；推送方 `a2opts` 的 split / max-connection-per-server、任务手动 `conns` 数字也作为上限；其余普通站点自动 8→64（快 CDN 128；A15 前是 32/64），不受 aria2 16 路硬顶限制。A15（2026-11-12）：设置「最大连接数」max_conns（自动/8/16/32/64/128）当全局上限；网盘规则默认值不变，netdisk_conn 覆盖到 >16 时自研引擎照走（`profile_conn(..., hard_max=128)`）；明确要求 >16 路时即使 speed_engine=aria2 也先走自研引擎（`SPD.needs_sdl`），失败回退 aria2（仍夹 16）。自动加连接：每加一批提升 <5% 就停并退回上一档；429/503 时按「正在出数据的连接数」学到上限，不再越过。
6. **代理**：`get_system_proxy()`；http/https/socks（SOCKS 需 PySocks，打包时加进 spec：`hiddenimports=['socks']`；缺了就 Fallback）。回环地址（127.0.0.1/localhost/::1）一律直连、不读环境变量代理。
7. **run_direct(eng, t, prog, headers)** 是整条任务版（自带名字推断、已存在跳过、过期预检、Cookie/Referer/UA 默认值、网盘上限）。当前建议不用它替换 `_rpc_direct_file`（原函数还有补后缀探测、curl_cffi 412 兜底），留给以后精简；用时 prog 传原始回调即可。
8. **PyInstaller**：SniffDL.spec 里加 `sdl_speed` 包与 `core.speed`；`requests/urllib3` 已有。
