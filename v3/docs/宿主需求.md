# 宿主 ↔ 界面约定（给 ui/ 子任务）

宿主（`pet_electron/app/main.js` + `preload.js`）已按 `ui/js/api.js` 现有期望实现，**界面无需改动即可跑通**（Xvfb 实测）。以下是约定与可选改进：

## 已实现的 `window.sniffdlHost`
| 方法 | 返回 | 说明 |
|---|---|---|
| `conn()` | `{port, token, pid, version}` | 内核没就绪时最多等 20 s，超时返回 `null`；内核被宿主重启后返回新端口/新 token |
| `pickDir(title)` | 路径 \| `null` | |
| `pickFile(filters)` | 路径 \| `null` | `filters` 用 Electron 格式：`[{name:'种子', extensions:['torrent']}]`，可省略 |
| `saveFile(name, text)` | 保存路径 \| `null` | 宿主弹「另存为」并把 `text` 写进去（UTF-8）；`text` 是对象时宿主转 JSON |
| `notify(title, body)` | `true/false` | 系统通知，点击唤回主窗 |
| `show()` / `quit()` / `setProgress(p)` | — | `quit()` 退出整个 SniffDL（关内核）；`setProgress(0..1)` 任务栏进度，`-1` 清除 |
| `kind` | `'electron'` | |

## 请界面配合（可选）
1. **重连时重新 `conn()`**：api.js 已在 SSE 出错时调 `discover()`，宿主重启内核后 token 会变——当前实现已能拿到新 token（实测通过）。保持这个逻辑即可。
2. **任务栏总进度**：宿主已提供 `setProgress`，界面目前没调。建议在 `stats` 事件里按「已下/总量」调用 `api.host.setProgress()`，全部完成时传 `-1`。
3. **通知开关**：界面目前只在 `document.hidden` 且设置 `notify !== false` 时调 `host.notify`，宿主不另行弹通知，避免重复。
4. **退出入口**：设置或菜单里若要「退出 SniffDL」，调 `api.host.quit()`（不要直接调 `sniffdl.core.shutdown`，那样宿主会当成内核意外退出并自动重启一次）。
5. CSP 已允许 `connect-src http://127.0.0.1:*`，界面以 `file://` 加载、Origin 为 `null`，内核 CORS 对带 `X-SniffDL-Token` 的请求放行——无需改动。
