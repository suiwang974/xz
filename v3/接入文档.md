# 桃桃 2.5D rig 版接入文档（定稿，给实现 agent）

本文档为唯一接入依据。调参细节另见后台参考 `RIG_TUNING.md`。

## 0. 交付物与版本

- PSD：`taotao-vivid-hair-seethrough.psd`（桃桃亮发版新母图，768×768，18 层，2026-10-27 由 HF 拆分，驱动实测通过；2026-10-28 复核文件完好）。
- 预览：`taotao-psd-composite.png`（拼合图）、`taotao-psd-layers-sheet.png`（分层总览）、`taotao-rig-check.md`（逐层对照表）。
- 1280 重跑已由用户叫停，本版就用 768，不等高清版。

## 1. 怎么用（两条路线，二选一）

- 路线 A（实时驱动，推荐）：用 Anime2.5DRig（MIT 开源，纯前端 JS + WebGL，演示站 https://852wa.github.io/Anime2.5DRig/）加载本 PSD，通过参数驱动。SniffDL 是 Tkinter，需要另外解决嵌入：单独窗口跑 rig 页面，或内嵌浏览器；不能直接把 PSD 塞进 Tkinter 当帧用。
- 路线 B（录制转帧）：在 rig 页面把动作录成 3–60 秒透明 WebM/MP4，再抽帧进现有帧管线。优点是 Tkinter 不用改，缺点是不是实时互动（点一下不能即时反应，只能播录好的）。
- 通用：不要改 PSD 图层名（rig 按名字识别）；结束姿势复位（角度 0、无预设、双眼 1/1）；设置调好后导出设置 JSON（与 PSD 配对，即调参文件）。

## 2. 图层表（后→前）

back hair → footwear → legwear → neck → handwear → bottomwear → topwear → ears → face → nose → mouth（mouth_open）→ mouth_close（通用差分）→ eyebrow L/R → headwear → eyelash L/R → eye_close L/R（通用差分）→ eyewhite L/R → irides L/R → front hair → objects（托盘蛋糕茶杯）。

- 绑定实测：25 部件、8 根发束（前发 2、后发 6）；face 80×92；neck 34×42；irides 高约 15px。

## 3. 参数表（实测确认）

- 双眼开度 L/R：0–1（0 闭眼，1 全开）
- 眉：-1–1（负值下压，正值抬高）
- 口开度：0–1
- 笑形：-1–1（负值撇嘴，正值笑）
- 瞳孔缩放：0.7–1（惊讶时 0.7）
- 头角度 X/Y：滑块 -1–1，实测效果约十几度，带真分层视差（瞳孔位移大于眼白、远侧眼轻微压缩、后发滞后）
- 自动开关：待机浮动、自动眨眼、随机动作、随机口型、头发物理（开）；鼠标跟随（桃桃图上实测未生效，勿依赖）
- 预设键：1 通常（眼 1/1、眉 0、口 0、笑 0、瞳 1）；2 闭眼笑（眼 0/0、眉 0.45、笑 0.9）；3 半睁眼笑（眼 0.5、眉 0.35、口 1、笑 0.8）；4 惊讶（眼全开、瞳 0.7、眉 1、口 0.75、笑 -0.1）；5 眯眼（眼 0.4、眉 -0.6、笑 -0.4）；6 左 wink（左眼 0 右眼 1、眉 0.2、口 0.4、笑 0.7）；7 右 wink（镜像）；0 解除复位。
- 预设期间自动眨眼与随机口型会被抑制（预设锁定眼睛/嘴状态），不是 bug。

## 4. 表情组合系统（五层叠加）

核心思想：最终脸 = 待机底层 + 主表情 + 头角度 + 嘴型层 + 眨眼层。各层独立时间线、可叠加。

- 待机底层（常驻）：呼吸浮动 + 头发物理 + 自动眨眼 + 偶尔随机小动作。
- 主表情层（一次一个）：从预设或自定义参数组里选，切换时参数插值过渡 200–300ms，禁止硬切。
- 头角度层（可叠加）：-0.5–0.5 常用，极限 ±1 只做短暂强调；歪头卖萌用 X ±0.3–0.5。
- 嘴型层（可叠加）：说话时随机口型或麦克风驱动；不说话时关闭。
- 眨眼层：自动眨眼常驻，但表情预设期间自动眨眼会被抑制；强调时可手动双眨。
- 优先级：触发反应（戳/拖）> 说话 > 主表情 > 待机。反应结束后 300ms 内插值回待机。
- 禁忌：不要同时开两个主表情；不要在主表情切换瞬间叠加头角度跳变；笑形负值与口开度大值不要同用（会成怪表情）；瞳孔缩放只在惊讶/害羞时动，平时保持 1。

## 5. 互动映射

### 5.1 点击计数（300–400ms 窗口内计次，超时清零；每次触发后冷却，防刷屏）

- 1 下：戳 → 预设 4（惊讶）0.5 秒 → 眨眼一次 → 回待机（沿用现有 poke 语义）。
- 2 下：喜欢 → 预设 2（闭眼笑）+ 头角度 X 0.3。
- 3 下：卖萌 → 预设 6/7（wink）+ 头角度 0.4 + 鼓嘴帧切换（见第 6 节）。
- 4 下：害羞 → 预设 5（眯眼）+ 笑 -0.4 + 视线撇开 + 气泡台词一句（走现有 talk 气泡系统，符号只用 ♡ ♪ ☕ ✦）。
- 5+ 连点：躲开 → 转头 + 冷却数秒不响应点击。

情绪递进：惊讶 → 开心 → 卖萌 → 害羞 → 躲开。

### 5.2 鼠标距离行为

- 远：视线跟随鼠标。注意：原版鼠标跟随在桃桃图上未生效，需脚本化视线（瞳孔层按鼠标方向小幅偏移）或摄像头跟随实现，不要直接依赖原版鼠标跟随。
- 近（进入约 100px 半径，起始值可调）：害羞躲开——视线迅速撇开 + 眼 0.5 + 笑 0.5，持续 0.8–1.2 秒。
- 偷瞄循环：躲开 1 秒后偷瞄回来一眼，再躲开；同一害羞行为冷却 5–8 秒。

### 5.3 日常/待机行为

- 底层常驻：呼吸浮动 + 头发物理 + 自动眨眼。
- 每 8–15 秒一次随机微表情：笑 0.3 / 头角度 ±0.2 / 看向用户 / 双眨，持续 2–3 秒回落。
- 每隔数分钟轮换生活小行为：看托盘、整理头发、打哈欠（眼半闭 + 口开）、发呆（视线放空、眨眼变慢）。
- 注意：rig 里手、脚、身体无独立动作，生活小行为只表现在头/脸/头发层。

## 6. 特殊反应（帧切换，不走 rig 参数）

- 鼓嘴：rig 参数无此项；单独一张鼓嘴帧，触发时切过去 0.8–1.2 秒切回（与现有 poke 受惊帧同路子）。
- 拖动：沿用现有 lift 帧逻辑（rig 不做拖动身体）。

## 7. 调参起始值（针对桃桃）

- 自动眨眼开；加 eye_close2 长眨眼层（20% 概率、10 倍时长；需另生一张闭眼图）。
- 眨眼间隔随机：平均 4 秒、随机 0–8 秒；闭合 0.1 秒、保持 0.05 秒、睁开 0.15 秒；偶尔双眨。
- 呼吸 3–4 秒周期、小幅度；头部摆动 ±1–2°、5–8 秒循环；胸部摇摆轻、身体倾斜轻。
- 前发柔软度中偏软（发梢飘逸是卖点）；后发跟随；闭合位置锚点按 E 模式核对一次；脖子锚点核对首旋转轴（neck 仅 34×42），实测无穿帮默认即可。
- 头角度常用 ±0.2–0.3，极限 ±1 只短暂强调；瞳孔缩放平时 1，只在惊讶/害羞时动。
- 调参操作：滑块数字直输、双击恢复默认、E 锚点、Ctrl+S + 导出 JSON；一次只调一个参数，看效果再调下一个。

## 8. 已知限制（实现时不要承诺超出部分）

- 转头仅十几度，无四分之三侧脸；鼠标跟随桃桃图未生效。
- 眨眼/闭口为通用差分，贴合但非专属画风；呼吸起伏轻微。
- 手、脚、身体无独立动作（仅随身体浮动）；托盘为静态 objects 层。
- 768 分辨率：脸 80×92、眼珠约 15px 高，近看细节粗；口开合为差分切换 + 变形简易表现，中间口型越多越顺滑。
- 1280 重跑已叫停。

## 9. 验收清单

1. 加载 PSD，25 部件绑定成功、预设 1–7 全响应、0 复位。
2. 待机 10 秒眨眼 ≥1 次、头发摆动可见、呼吸浮动可见。
3. 点击 1/2/3/4 下反应与第 5.1 节一致；连点冷却生效。
4. 鼠标靠近触发害羞躲开 + 偷瞄；远离恢复视线跟随（脚本化实现）。
5. 转头极限角度脖子无穿帮；反应后 300ms 内回待机。
6. 设置 JSON 导出可用，与 PSD 配对加载后效果一致。
