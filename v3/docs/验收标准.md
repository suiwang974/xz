# SniffDL 验收标准（用户要求汇总，2026-11-12 整理）

只有全部满足才算结束：

1. **功能对标 IDM 及以上**：多连接动态分片且速度优化到最好；浏览器接管下载（Edge、Chrome 插件，含 POST 表单下载）；网页视频悬浮下载按钮与嗅探；队列与计划任务；全局/单任务限速；剪贴板监听；BT/磁力；断点续传；网盘直链推送（LinkSwift 等走 aria2 RPC 127.0.0.1:6800 无 token，必须兼容，保留推送方的 Cookie/UA/Referer 并真正落盘）。
2. **好用**：默认开箱即用、主界面简洁、高级项折叠；中文界面；商业级精致度；大肥鱼蓝；深浅色都好看。
3. **生态**：下载器与 Edge/Chrome 插件平级配合，与大肥鱼桌宠联动。
4. **Windows 成品**：打包成 Windows 版（解压即用），放到 GitHub。
5. **Windows 实测全部功能无问题**：在云端 Windows 上跑，用测试报告和录屏证明效果；用户不在自己电脑上测试，不把用户当测试员。
6. **交付规矩**：自己在真程序上测通过再交；不敷衍、精益求精；交接坦率列出不足；用户说「好了」才打包推送交付物。
7. **安全与合规**：源码和 config 不留 API 密钥；不用生图 API；不引入来源不明的网络图；猫抓（GPL-3.0）只参考思路，clean-room 实现；推 GitHub 前排除用户数据与日志。

## 2026-11-12 19:57 用户追加
