## 未测 / Windows 待自测
1. **托盘**：Xvfb 无系统托盘，菜单项（显示主窗、开始/停止全部、乌龟模式勾选、从剪贴板导入、显示/隐藏大肥鱼、Q版切换、退出）只做了代码审查。逐项点一遍；乌龟模式勾选应与界面状态同步（宿主每 15 s 读一次设置）。
2. **关闭主窗进托盘**：点 ✕ 后主窗隐藏、进程/内核/下载照常；托盘单击/双击能唤回。
3. **系统通知**：主窗在托盘里时下载完成应弹 Windows 通知（界面只在 `document.hidden` 时调 `host.notify`）；点通知应唤回主窗。Windows 需 AppUserModelId（已设 `SniffDL`），未装快捷方式时通知可能不显示——打包时确认。
4. **内核启动命令**：Windows 优先 `程序目录\SniffDL.exe --core`，否则 `python sniffdl_core.py`（可用 `SNIFFDL_PYTHON` 或 `SNIFFDL_CORE_CMD='["…"]'` 覆盖）。打包布局确定后核对 `coreCmd()` 的查找路径。
5. **强杀宿主**（任务管理器结束 electron.exe）：内核应靠 `--parent-pid`/stdin 关闭在 ≤2 s 内退出，aria2c 靠 `--stop-with-process` 跟着退。
6. **单实例**：双击两次快捷方式只开一个，第二次把主窗拉到前面（含最小化/在托盘的情况）。
7. **桌宠**：鼠标穿透/命中门控、拖拽甩动、Ctrl+Alt+H、`%APPDATA%\SniffDLPet` 下小本本/好感度跨重启保留（userData 目录未变）。
8. **桌宠控制端口 6801 被占**（旧版独立桌宠还开着）：宿主会退到随机端口并把新端口传给内核，确认旧桌宠不会和新桌宠同时出现。
9. **对话框**：设置里选目录（pickDir）、导入 .torrent（pickFile 带 filters）、导出任务（saveFile 写文件）在 Windows 下的默认目录与中文路径。
10. 高 DPI（125%/150%）下主窗最小尺寸 980×640 与桌宠铺满工作区。
