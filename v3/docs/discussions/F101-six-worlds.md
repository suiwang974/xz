# F101: 六界各司其职（把"皮肤"升级成"人格 + 专长"）

## 起因

用户诉求：六个世界不能只是换皮换色，要有**各自的功能/专长**，让人多巴胺拉满；并提到"多世界记忆/并行"的设想（A 世界下载时 B 世界还能继续嗅探……）。

## 对"并行下载"设想的判断

**不做真并行**。带宽、连接数、账号风控都是硬上限，多开下载器只是把同一条管子切成几段，反而更容易被站点限流/封号。但用户想要的"记忆"是真需求——只是它不该是"并发能力"，而该是**每个世界记住自己那摊事**。所以下面把"记忆"落到具体专长上（尤其汉界的资源档案，复用我们已有的 downloaded.json 历史）。

## 核心设计：换世界 = 换"当值专家"

不是六个皮肤，是六位**分工不同的专员**。切到某个世界，主界面会把它最擅长的那块工具顶到前台；插件弹窗也会自动染成该世界配色、显示该界看板娘。默认（女仆）是全能总管，其余五界各管一摊：

| 世界 | 看板娘 | 人设 | 专属功能（切到它时前台强化的模块） |
|---|---|---|---|
| 女仆 maid | 桃桃 | 贴身管家·全能 | **任务调度中心**：队列、断点续传、限速、完成后动作、接管总开关。默认界，最抢眼。 |
| 汉界 hanfu | （汉服） | 藏书阁·文士 | **资源档案/记忆**：下载历史、按来源与类型归档、命名规范化、**同链接去重**（"这个下过了"）——把用户的"记忆系统"诉求实现在这里。 |
| 魔界 magic | 莉兹 | 占星·塔罗·揭秘 | **深度嗅探专家**：整站嗅探、列表页→详情页、m3u8/流媒体识别与解密捕获、反爬指纹伪装。塔罗=揭示隐藏之物=揪出藏起来的链接。 |
| 巫界 miko | （巫女） | 结界·守护 | **安全与流量结界**：链接/域名风险扫描、恶意文件提示、Cookie 与隐私守护、流量与并发"结界"上限（别把带宽和账号搞爆）。 |
| 机界 robot | （机器人） | 自动化·工业 | **批量与内核调度**：多线程/分片调优、定时任务、清单/RSS 批量、命令行/API、**BT/磁力 + aria2c 内核**（重活脏活它干）。 |
| 哥界 goth | （哥特） | 夜行·隐秘 | **隐身与抢救**：代理/无痕切换、下载接管（悄悄把浏览器下载截走）、失败重试与断点抢救、暗色沉浸模式。 |

## 这样设计的好处

1. **差异化护城河**：IDM/Motrix 是"一个工具"；我们是"一个住着六位专员的家"，每换一界手感都不同，情绪价值 + 实用价值双高。
2. **不增架构负担**：功能本来就都要做（调度/档案/嗅探/安全/批量/隐身），只是把它们**归到各界名下、切界时前置**，不是新造能力。
3. **记忆有落点**：汉界档案 = 真·记忆；各界还能记住自己的最近目标/设置/常用参数（轻量，零并发成本）。
4. **插件跟着变身**：新增 RPC 方法 `sniffdl.theme` 返回当前世界配色 + 看板娘标识，浏览器插件弹窗据此自动换肤，实现"六个世界各自的适配"。

## 分期落地

- **P1 插件**：先做"接管下载 + 弹窗自动读 sniffdl.theme 换肤 + 桃桃（默认界）"。
- **P2**：魔界莉兹接深度嗅探（悬浮按钮/整页嗅探本就是嗅探，天然归她）。
- **P3**：机界接 aria2c 内核 + BT/批量/定时。
- **P4**：汉界资源档案与去重（复用历史）；巫界安全/流量结界；哥界隐身/代理/抢救。
- **贯穿**：每界一个"当值面板"，切界 = 换肤 + 换前置工具 + 换看板娘台词。

## 待你拍板的点

- 这张"六界分工表"你认不认？哪界的功能想调/想加？
- 切界时"前置对应工具"你更喜欢**自动切换**（切到魔界自动展开嗅探面板）还是**手动**（皮肤换、工具面板你点开）？
